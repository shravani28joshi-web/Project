# Criminal Investigation Tracker with Suspect Prediction

A web-based Criminal Investigation Tracker designed to help manage crime-related data such as cases, suspects, evidence, and alerts.  
The system provides multiple modules for crime analysis and investigation support, with scope for intelligent suspect prediction.

---

## 📌 Project Overview

The Criminal Investigation Tracker is developed as an academic project to demonstrate the use of web technologies in building a structured crime management system.  
It offers different portals and dashboards to view, analyze, and manage crime-related information efficiently.

---

## 🎯 Objectives

- To maintain organized records of criminal cases
- To provide separate modules for different crime categories
- To assist investigators with pattern analysis
- To improve case monitoring through alerts and dashboards
- To lay a foundation for future suspect prediction using analytics

---

## 🧩 Modules / Pages

- **Login Page** – Secure access to the system  
- **Admin Panel** – Centralized control and monitoring  
- **Dashboard** – Overview of cases and system statistics  
- **Cases Overview** – Displays registered criminal cases  
- **Evidence Management** – Handling and tracking evidence details  
- **Alerts & Notifications** – Important updates and alerts  
- **Crime Against Women Portal** – Focused crime category module  
- **Financial Frauds Portal** – Financial crime analysis  
- **Investigator Access Control** – Role-based access  
- **Pattern Analysis** – Crime trend and pattern visualization
